# Assignment 1 — Market Basket Analysis (MBA) on Real-World Data

## Objective
Apply Market Basket Analysis (the Apriori algorithm) to real transactional
data to find frequently co-purchased items and generate association rules
(support, confidence, lift).

## Dataset
- **Primary (real data):** [UCI "Online Retail" dataset](https://archive.ics.uci.edu/dataset/352/online+retail) —
  ~540,000 real invoice-line transactions from a UK-based online retailer
  (Dec 2010 – Dec 2011). The script downloads this automatically.
- **Fallback:** `grocery_transactions.csv` (included in this folder), a
  400-transaction sample with realistic grocery co-purchase patterns
  (bread+butter+jam, diapers+beer, pasta+sauce+cheese, etc.), used
  automatically only if the download fails (e.g. no internet access on the
  lab machine). Generated by `generate_grocery_data.py`.

## Method
1. Convert each transaction (invoice) into a list of purchased item names.
2. One-hot encode transactions into a basket matrix (`TransactionEncoder`).
3. Run the **Apriori algorithm** to find frequent itemsets above a minimum
   support threshold.
4. Generate **association rules** from those itemsets, filtered by minimum
   confidence, and rank by confidence and lift.

## Files
| File | Purpose |
|---|---|
| `mba_analysis.py` | Main script — download real data (or fall back), run Apriori, generate rules |
| `generate_grocery_data.py` | Generates the fallback sample dataset |

## How to run (Windows)
```powershell
pip install pandas mlxtend openpyxl
python mba_analysis.py
```

## Interpreting results
- **Support** — how often the itemset appears across all transactions.
- **Confidence** — P(consequent | antecedent): how often the rule holds true.
- **Lift** — how much more likely the consequent is, given the antecedent,
  compared to chance (lift > 1 means a genuine positive association).

## Sample findings (fallback dataset)
`{Milk}` and `{Bread}` are the most frequent single items. Strong rules such
as `{tomato sauce, cheese} -> {pasta}` show confidence = 1.0 and high lift,
meaning customers who buy pasta sauce and cheese almost always also buy pasta.
